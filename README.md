# Montage automatique (skills Claude)

Skills de montage pour Claude Code (app Claude, onglet Code, session locale).

- `skills/montage` : point d'entrée du montage vidéo. Lance les briques demandées puis fabrique la vidéo en un seul rendu depuis l'originale.
- `skills/couper-silences` (brique) : coupe les silences, les reprises (garde la dernière prise) et les faux départs.
- `skills/sous-titres` (brique) : sous-titres au style de Romain, orthographe corrigée par Claude.
- `skills/carrousel` : met en page un carrousel Instagram (1080 × 1350) au style Fit avec Romain, à partir de ses photos et de son texte exact. Fond noir ou photo.

## Installer

Dans l'app Claude, onglet Code, en session locale, colle le prompt d'installation fourni par Yoan.
