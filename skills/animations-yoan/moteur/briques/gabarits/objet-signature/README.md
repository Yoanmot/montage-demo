# objet-signature (gabarit 5)

Petit objet en verre (190 à 210 px) à côté de la tête : net depuis un flou en 5 images, il vit pendant la phrase,
repart dans un flou. `objet: 'fichier'` (page à coin plié, lignes qui s'écrivent, onde dorée = la voix) ou
`'horloge'` (cadran, aiguille dorée qui tourne).

`objetSignature(p, { objet, cx, cy, taille, entree, sortie, lignes: [t...], accent: t, tour: { t0, t1, tours }, etiquette: { texte, t }, etiquettes })`

Usage : une métaphore courte (le fichier, le temps, la quantité). Placement : à droite de la tête au-dessus de y 997
(x jusqu'à 990), étiquette comprise. Son : un tic à l'apparition. Exemple : r10-02c.
