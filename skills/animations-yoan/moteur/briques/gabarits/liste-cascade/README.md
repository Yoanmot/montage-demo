# liste-cascade (contenu de panneau)

Une ligne par idée dite : tuile d'icône (rayon 16) + texte d'interface (Inter) + étiquette à droite ; chaque ligne
entre depuis un flou en glissant de 14 px, calée sur son mot ; les crochets dorés se resserrent sur la première, puis
glissent de ligne en ligne (0,22 s, power2.inOut).

`listeCascade(p, { w, y0, pas, items: [{ icone, texte, tag, t }], actif: [{ t, i }], etiquettes })`

Icônes disponibles : `ICONES` de commun.mjs. Exemple : r10-03a.
