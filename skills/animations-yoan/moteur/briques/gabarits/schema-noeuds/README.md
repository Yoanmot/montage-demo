# schema-noeuds (contenu de panneau)

Nœuds (tuile d'icône 150 px + étiquette) qui éclosent un à un (de presque rien à 100 % en 0,15 s, sans dépassement),
traits crème qui se tracent de l'un à l'autre (0,35 s), crochets dorés sur le nœud dont on parle, consigne qui se
tape dans un champ en bas du panneau.

`schemaNoeuds(p, { noeuds: [{ x, y, icone, etiquette, t }], tuile, liens: [{ de, a, t, d }], actif: [{ t, i }], consigne: { y, texte, debut, cps, t }, etiquettes })`

Exemple : r10-04a (et r10-05a/b/c pour la famille d'étiquettes).
