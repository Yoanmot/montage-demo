# vignette-morph (gabarit 6)

Vignette à viseurs ; un grand chiffre (Satoshi Black 300 px) arrive au centre avec son unité ; sur le mot suivant il
file vers le haut gauche en rétrécissant et devient une pastille dorée (0,35 s, power2.inOut) ; un titre se pose à
côté ; une liste éclot dessous, ligne par ligne.

`vignetteMorph(p, { box, entree, fin, chiffre: { texte, unite, t, taille }, pastille: { t, d, diametre }, titre: { texte, t }, lignes: [{ icone, texte, t }], etiquettes })`

Usage : un chiffre qui devient une étiquette, puis ce qu'il recouvre. Son : un tic sur le morph. Exemple : r10-04b.
