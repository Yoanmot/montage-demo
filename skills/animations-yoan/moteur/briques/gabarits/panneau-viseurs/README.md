# panneau-viseurs (gabarit 3)

Panneau de verre sombre (83 % de la largeur, x 90 à 990), filet crème 1,5 px, angles quasi droits, grain qui vibre,
croix « + » crème aux 4 coins (bras qui dépassent), ligne d'en-tête à deux étiquettes. Le panneau ne bouge pas ; seul
son contenu se construit. En plein écran, haut à y 560, bas laissé vide (tiers bas sombre).

`panneau(p, { x, y, w, h, entree, sortie, entete: { gauche, droite, t }, etiquettes, contenu })`

Contenus prévus : `liste-cascade`, `schema-noeuds`. Exemples : r10-03a (demi-écran), r10-04a et r10-05 (plein écran).
