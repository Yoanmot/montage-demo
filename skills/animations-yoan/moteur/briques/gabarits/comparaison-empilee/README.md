# comparaison-empilee (gabarit 7)

Deux vignettes l'une sous l'autre (verre sombre, fond chaud flouté, grain), chacune avec son étiquette espacée
dessous ; la seconde arrive sur le mot qui la porte ; les crochets dorés passent de la première à la seconde et
l'étiquette active passe au doré.

`comparaisonEmpilee(p, { x, w, cartes: [{ y, h, titre, texte, etiquette, t }], actif: [{ t, i }], etiquettes, sortie })`

Usage : avant / après, sans / avec, V1 / V2. Exemple : r10-03b (en demi-écran).
